# Tipografía Doran

El libro de marca usa **Doran** (latín y árabe). Es una fuente de pago y no venía incluida en el PDF.

1. Pide a la agencia los archivos con **licencia web** (o cómprala).
2. Conviértelos a `.woff2` si vienen en `.ttf`/`.otf`.
3. Guárdalos aquí como `Doran-Light.woff2`, `Doran-Regular.woff2` y `Doran-Bold.woff2`.
4. En `src/config.js` pon `site.doranFonts = true` y sube los cambios.

Mientras tanto la web usa Bodoni Moda (latín) y Noto Naskh Arabic (árabe), las alternativas libres más parecidas.
